TeleCalc is a privacy-focused Telegram client that disguises itself as a calculator app.

<b>How It Works</b>
On first launch, you set a secret numeric code. After that, the app always opens as a fully functional Material You calculator. To access Telegram, type any math expression whose result equals your secret code and press equals. Telegram opens instantly. To everyone else, it looks like a normal calculator.

<b>Calculator Decoy Features</b>
- Material You styled calculator (light purple palette, rounded buttons)
- Basic operations: addition, subtraction, multiplication, division
- Secret code stored as salted SHA-256 hash
- Instant transition to Telegram on correct code entry
- Re-entry required every time the app is reopened
- Screenshot protection (FLAG_SECURE)
- Notification previews disabled by default
- Change secret code from hidden debug menu

<b>Inherited Telegram Features (via Forkgram)</b>
- Delete for everyone enabled by default
- Original message date for forwarded messages
- Online colored status dots
- Quick share button for media
- PiP mode for YouTube
- Forward without quoting original sender
- Unlimited pinned chats
- Fast Forward with anonymous and no-text options
- Hidden proxy string and account names
- And many more privacy and convenience features
